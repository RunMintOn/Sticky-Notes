## Links & Images

Link: [GitHub](https://github.com)

Images use standard Markdown syntax. Paste from clipboard or insert via the toolbar.

## Shortcuts

- **Bold** — Ctrl + B
- **Highlight** — Ctrl + H
- **Strikethrough** — Ctrl + D
- **New note** — Ctrl + N
- **Help** — F1

## Interaction Tips

- Move the caret onto a line to reveal its Markdown markers.
- Optionally enable hover reveal in Settings.
- Select text and type three backticks to wrap it in a fenced code block.
- Press Enter to continue lists; Enter on an empty item exits.
- Press F1 for the full help page.
