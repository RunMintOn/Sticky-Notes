# Win Sticky Notes — 功能展示

欢迎！这条便签展示了当前支持的所有 Markdown 格式。

## 文字格式

**粗体 Bold** · *斜体 Italic* · ~~删除线 Strikethrough~~ · ==高亮 Highlight==

行内代码：`const x = 1;`

## 代码块

```text
┌─────────────────────┐
│  代码块使用连续深色   │
│  背景，右上角有复制   │
│  按钮，只复制正文。   │
└─────────────────────┘
```

## 水平分隔线

---

## 列表

### 无序列表

- 第一项
- 第二项
  - 嵌套项
- 第三项

### 有序列表

1. 第一步
2. 第二步
3. 第三步

### 任务列表

- [x] 已完成任务
- [ ] 未完成任务
- [ ] 待办事项

### 引用

> 这是引用块。
> 支持多行。
> 样式为斜体加浅色文字。

## 链接与图片

链接：[GitHub](https://github.com)

图片使用 Markdown 标准语法。支持从剪贴板粘贴或通过右键菜单插入。

## 快捷键

- **加粗** — Ctrl + B
- **高亮** — Ctrl + H
- **删除线** — Ctrl + D
- **新建便签** — Ctrl + N
- **帮助** — F1

## 交互提示

- 光标位于某行时，该行的 Markdown 标记会显示出来。
- 在设置中可以改为鼠标悬停时显示。
- 选中文字后连续输入三次反引号 `` ` ``，会自动升级为代码块。
- 回车自动续写列表，空项目再次回车退出。
- 按 F1 随时查看帮助。

以上是当前版本的全部支持功能。
