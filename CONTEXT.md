# Sticky Notes

A lightweight desktop workspace for short, independently positioned Markdown notes.

## Language

**Note Window**:
An independently positioned window containing one note.
_Avoid_: Tag, label, small window

**Notes List**:
The management window used to search and reopen notes.
_Avoid_: Main panel, management panel

**Note Card**:
A content-sized summary of one note inside the Notes List.
_Avoid_: List item, tile

**Open Fold**:
The folded lower-right corner of a Note Card indicating that its Note Window is currently open.
_Avoid_: Triangle, resize handle

**Accent Command Bar**:
The note-colored strip at the top of a Note Window. It expands to expose note-level commands without moving the note content.
_Avoid_: Yellow bar, title bar, top strip

**Editor Surface**:
The stable content area in which a note is read and edited.
_Avoid_: Text box, body panel

**Formatting Toolbar**:
The command row at the bottom of a Note Window for applying Markdown formatting.
_Avoid_: Bottom icons, bottom bar

**Note Menu**:
The overlay opened from the Accent Command Bar for color, navigation, and deletion actions.
_Avoid_: Three-dot popup, right-click menu

**Settings Page**:
The in-place Notes List page for appearance and editing preferences.
_Avoid_: Settings popup, settings window

**Live Preview**:
The single-view editing behavior that renders Markdown while revealing source markers around the pointer or caret.
_Avoid_: Preview mode, rendered mode
